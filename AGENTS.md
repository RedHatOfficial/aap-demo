# Agent notes

[README.md](README.md), [CONTRIBUTING.md](CONTRIBUTING.md), and [docs/](docs/index.md)
are the sources of truth. Do not invent policy that is not written there.

The documentation set is OKF compliant and indexed from
[docs/index.md](docs/index.md). Put longer explanations there. Keep the
front matter (`type`, `title`, and `description`) on those pages.

[README.md](README.md) stays a friendly quick start plus links. The reader
is less technical than the maintainer. Do not move contributing rules,
design notes, or implementation detail onto that page.

[CONTRIBUTING.md](CONTRIBUTING.md) is how a change is set up, tested,
committed, and opened as a pull request.
